# Saldo

Household budget web app — see income, expenses, and what remains.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Local React state (SR/EN i18n, light/dark theme)

## MVP scope

Income · Expenses · Saldo · Rule-based savings advice
